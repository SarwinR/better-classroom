# Better Classroom Privacy Policy  

_Last updated: September 27, 2025_  

Better Classroom is a free and open-source browser extension that enhances Google Classroom by allowing users to organize their classes into folders.  

## Data Collection and Storage  
- **No Personal Data Collected**  
  Better Classroom does not collect, transmit, or store any personally identifiable information (PII).  
- **Local Storage Only**  
  The extension stores Google Classroom class IDs and folder information **only in the user’s browser extension storage**. This data never leaves the user’s device.  
- **No External Servers**  
  Better Classroom does not send data to any external servers controlled by the developer or third parties.  

## Data Use and Sharing  
- Data saved in the extension is used **solely to provide the folder and class organization features**.  
- Better Classroom does **not** share, sell, or disclose data to any third parties.  
- The extension contains **no tracking, advertising, or analytics tools**.  

## User Control  
- All stored data remains fully under the user’s control.  
- Users may delete all extension data at any time by clearing their browser extension storage or uninstalling the extension.  

## Security  
- Because all information remains local to the browser, it is protected by the user’s own device and browser security settings.  
- No remote transmission occurs, so risks related to data breaches at vendor servers do not apply.  

## Transparency  
- Better Classroom is open-source software. Its source code is publicly available for review, ensuring full transparency of how it works.
